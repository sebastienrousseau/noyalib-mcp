# noyalib-mcp 0.0.59 interim build

These binaries and container build from the exact reviewed Git revision
`399ec598b509a728eb13f4e82be0a2526137e81f` of RustCrypto const-oid, including
Jaideep Pyne's merged overflow fix in
[RustCrypto/formats#2412](https://github.com/RustCrypto/formats/pull/2412).
They use published core `=0.0.59` and MCP SDK 3.9.0.

This is a prerelease distribution of the 0.0.59 source tree. Crates.io, npm
and MCP registry publication remain pending a fixed upstream registry
release. The stable container latest tag is unchanged. Download the archive
for your platform from this page, or use the versioned container tag shown
in the release workflow. Binary `--version` reports the underlying 0.0.59
crate version; the archive and image tag identify the interim build.

Each archive and dependency-evidence file carries a Sigstore bundle and
GitHub provenance. `SHA256SUMS.txt` covers their bytes. The signed tag,
Cargo.lock, SBOM.txt, cargo-metadata.json and reviewed source-hash inventory
record the exact source used. A working source build can be made by
checking out this signed tag and running `cargo build --release --locked`.

The existing core no_std implementation, MCP API and Rust 1.89.0 support
remain unchanged. Overflow regressions run before publication against the
same pinned source used by the MCP dependency graph.
