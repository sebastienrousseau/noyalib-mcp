# noyalib-mcp 0.0.64

Release date: 2026-11-24. Remaining release-page sections are generated
at release time.

## Highlights ⭐️

* **Core 0.0.64**: the exact core pin, `server.json`, `glama.json` and the npm wrapper move to 0.0.64. The core accepts and refuses exactly what 0.0.63 did, so tool output is unchanged.
* **Dependencies**: `rmcp` 3.10.0 (#159), `taiki-e/install-action` 2.90.5 (#160) and the `rust:1.100-bookworm` container build image (#158).
* **In lockstep with noyalib 0.0.64**, which screens printable-ASCII plain and block scalars before the byte-level printable checks, cutting the x86_64 parse cost v0.0.62 added, and moves its lockfile to `url` 2.5.9 for RUSTSEC-2026-0592.
