# noyalib-mcp 0.0.56

Hand-written Highlights for the GitHub release page; the rest of the page
(What's Changed, Checksums, Full Changelog) is generated at release time.

## Highlights ⭐️

* **The npm wrapper ships**: `npx @sebastienrousseau/noyalib-mcp` works from this release. The step that writes its verified digests failed on the Windows archive in 0.0.55; it is fixed and now tested in CI against real archives for every platform.
* **In lockstep with noyalib 0.0.56**: the exact core pin moves to `=0.0.56`, so this release picks up the core's nesting ceiling and early `max_events` refusal.
