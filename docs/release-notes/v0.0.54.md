# noyalib-mcp 0.0.54

Hand-written Highlights for the GitHub release page; the rest of the page
(What's Changed, Checksums, Full Changelog) is generated at release time.

## Highlights ⭐️

* **In lockstep with noyalib 0.0.54**: the exact core pin moves to `=0.0.54`, so this release picks up every core change for that version.
* **File tools confined to a root**: `noyalib_get`, `noyalib_set` and `noyalib_set_multidoc` resolve every path against the server root (the working directory, or `--root DIR`) and refuse anything that lands outside it, symlinks included. A client could previously touch any YAML file the process could open.
* **Strict parsing by default**: `noyalib_parse` and `noyalib_validate` use noyalib's strict YAML 1.2 profile, so duplicate keys and odd indentation are errors and the tighter limits for untrusted input apply. `--profile standard` restores the previous behaviour.
* **Release gate covers cargo-deny**: a tag is refused while `deny.toml` allows a git source, so the allowance the iteration needs for the core's branch cannot ship.
