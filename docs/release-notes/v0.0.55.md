# noyalib-mcp 0.0.55

Hand-written Highlights for the GitHub release page; the rest of the page
(What's Changed, Checksums, Full Changelog) is generated at release time.

## Highlights ⭐️

* **Safer file tools**: every path is walked from an open handle on the root without following symlinks, writes keep the file's permissions and use an exclusive temp file, and only regular files up to the document limit are read, off the async workers.
* **Browser-proof SSE transport**: `--transport sse` refuses a request whose `Host` or `Origin` is not local, so a web page can no longer reach the tools through DNS rebinding.
* **Bounded requests**: schemas over 64 KiB are refused before compiling, `noyalib_validate` lists at most 100 violations, edits are depth-checked, and the HTTP transports hold at most 64 sessions (`--max-sessions`).
* **In lockstep with noyalib 0.0.55**: the exact core pin moves to `=0.0.55`, so this release picks up every core change for that version, including limits enforced on every loader and linear-time parsing of long lines.
