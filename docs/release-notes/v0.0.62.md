# noyalib-mcp 0.0.62

Release date: 2026-11-17. Remaining release-page sections are generated
at release time.

## Highlights ⭐️

* **Core 0.0.62**: the exact core pin, `server.json`, `glama.json` and the npm wrapper move to 0.0.62. Tools now return a parse error for a byte order mark inside plain text, and error paths read `items[0].name`.
* **Dependencies**: the github-actions group (#154) and uuid 1.29.2 (#153), with a cargo-vet delta audit from a review of the published crate diff.
* **In lockstep with noyalib 0.0.62**, the family's release after 0.0.60 (v0.0.61 was folded in and never published).
