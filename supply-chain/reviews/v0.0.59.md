# Dependency source review for v0.0.59

Reviewed on 2026-11-09 against the published crates.io archives. Each
archive's SHA-256 matches the production Cargo.lock, and every packaged
source file matches the extracted source used for review. Baseline
archives were independently checked against crates.io version metadata.

## Core 0.0.58 to 0.0.59

The published target archive has SHA-256
`8d99aeedb93b24d2416edd7de7946ddedce9942af917cbc78b0d9a9ecca83bad`.
Its VCS revision is `abcb2fed43d9a4693bb119d6f7f46947481d429a`.
This is a source delta review, including the portable float implementation,
CST growth and source spans; it is not a metadata-only change.

The crate continues to forbid unsafe code. The delta adds no ambient
filesystem, network or process capabilities. Private float helpers use
bounded integer operations and guarded shifts, including sticky-bit and
IEEE exponent boundaries. CST edits validate candidate text under the
original parser configuration and retain rollback on failure. Source
retention remains subject to parser budgets. Existing include and I/O
interfaces remain caller controlled and feature gated.

The published release's validation covered default and alloc-only tests,
Miri, bare-metal compilation and independent consumers. These checks
support the source review; they do not constitute a proof of all parser
semantics or all floating-point inputs.

## Satellite source delta

Compared with the independently downloaded v0.0.58 archive, this release's
runtime Rust source is unchanged. The serde-yaml adapter changes only its
crate-level documentation's version example. Dependency changes require
their own records; the satellite metadata review does not certify them.

## JSON Schema support, 0.58.5 to 0.60.2

Reviewed both complete source deltas. The regex translator adds linear
character-class escaping using UTF-8 character boundaries and a fixed
whitespace table. Its peek/consume operations and replacement offsets
remain bounds checked. No unsafe code or ambient capabilities are added.

The value crate adds bounded materialization of decimal exponents,
text-based decimal comparison, modular divisibility and insertion-order
independent object comparison. Saturating exponents and the 10,000-digit
materialization limit avoid allocating exponent-sized buffers. The build
script is unchanged. New memchr usage is a pure byte search; Python/Ruby
integration remains optional and is not enabled by these consumers.
No new unsafe block or filesystem/network/process import occurs in the
delta. This review does not claim arbitrary-precision mathematical proof.

## MCP SDK and cryptographic support

The SDK 3.5.1 to 3.9.0 delta was reviewed at upstream revision
`5596a8a0bba2a1ec5519cc855cdadf23e4dcecdc`.
Runtime source adds no unsafe block. Reviewed bounded JSON and error-body
reads, decompressed-byte counting, bounded stdio records, same-origin
307/308 redirects, filtered OAuth DNS connections, request/session
association, schema-cache removal, child-process cancellation cleanup and
enterprise authorization bindings. Explicit caller-supplied HTTP clients,
proxies and private-network opt-ins remain caller trust decisions.
The macros crate's Rust source is byte-identical to 3.5.1.

Reviewed block-buffer cursor/initialization invariants and panic guards;
hybrid-array layout, initialized-prefix guards, sealed size contracts,
checked lengths and disjoint mutable slices; crypto-common/digest's
safe-Rust traits and code generation; and typenum's generated arithmetic.
Typenum has no enabled build script. SHA-2's hardware dispatch guards,
SIMD pointer bounds and software schedule indexing were reviewed. Default
and software paths were executed; this is not a formal cryptographic
proof or execution of every architecture-specific backend.

Observed upstream tests on the exact archive sources:

- Crypto workspace on Rust 1.89: 1,985 passed, zero failed.
- Six crypto crates on Rust 1.99: 163 passed, zero failed. Typenum's strict
  development lint rejects deprecated standard constants on that compiler;
  its full test suite passed on Rust 1.89 without lint suppression.
- SHA-2's documented software backend: 16 passed, zero failed.
- Block-buffer and hybrid-array under Miri with symbolic alignment:
  111 passed, zero failed.
- MCP SDK unit and targeted transport/session security tests:
  847 passed, zero failed, zero ignored.

`const-oid 0.10.2` is deliberately not certified by this review. A local
probe reproduced an arc-overflow parsing error. No fixed newer registry
version was available at review time. The MCP release remains gated by
its existing cargo-vet policy until that review is resolved.
