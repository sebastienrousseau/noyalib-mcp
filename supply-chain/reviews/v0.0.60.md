# Release metadata source review

Authenticated core 0.0.59 and 0.0.60 registry archives were compared before
preparing this release. All packaged Rust sources match byte for byte;
dependencies, features, target declarations and Rust 1.89.0 also match.
Core 0.0.60 archive SHA-256: `c4f58e0d7f94aac1ff656e07a05512093b0a0f866f5778f94e84909f50fc3157`.

MCP runtime Rust is unchanged from the verified published 0.0.59 release.
The exact core pin and release metadata move together; the locks also
update Rustix and the npm package gains its declared license files.
The reviewed SDK/crypto sources, registry const-oid 0.10.3 certificate and
source/regression checks are retained. No trust, exemption, audit policy
or publisher workflow changes accompany this release. Rustix 1.1.6 is
updated in both locks from Dependabot PR148; its authenticated archive
was published by the already trusted Dan Gohman (crates.io user 6825)
within the existing trust interval. No new trust record is added.

The reviewed relevant source delta fixes truncated ancillary-message
buffer bounds, platform padding representation and several platform
filesystem/syscall constants. The package retains Rust 1.65, below this
crate's Rust 1.89 floor. MCP's filesystem operations and full matrix
are verified separately before publication. Archive SHA-256:
`e5e76742e5294153d4dde1207dbec5bdd81eef6fabdc0d2118babadabfd858aa`.
