# v0.0.61 source delta

Reviewed aa3c9db6409c108bc5c1911c076181763a965021 through 3a07fd7060648cdfda6bc68b006732daa537d2ef and the follow-up release preparation changes
described below.

Against the held signed v0.0.60 source, the SDK and production crypto graph retain their versions. Tool metadata now describes arbitrary JSON and nullable types with portable schema objects. Captured pre-change schemas and positive/negative instances verify the same accepted value contract. Strict Inspector passes with no schema findings. The fuzz workspace updates Tokio and adds HTTP guard coverage. The wrapper recovery drill uses an isolated cache and the real published v0.0.59 package and archive.

The exact core pin advances to v0.0.61. Review was refreshed through signed
core source `a57b7198669e41fe3034db4e44f2e274baf96388`, compared with
signed v0.0.60 source `2b3966235352c44b70071390faf6f06ec8b4d65d`.
Runtime source changes include:

- First-result queries use an iterative visited-state traversal. All-result
  queries memoize unsuccessful states, preserving match order and duplicates.
  Visited identities refer to immutable borrowed values; no pointer is
  dereferenced through unsafe code.
- Serialization quotes binary-looking strings recognized by the legacy
  resolver, preserving compatibility-mode mapping keys and scalar types.
- Clip chomping preserves a final line break only when the input has one.
  EOF behavior changes and is documented as breaking under the patch policy.
- Both AST loaders preserve anchor declaration order through nested
  redefinitions and shadow previous values while a new collection is open.
  Typed streaming uses the existing AST fallback for nested declarations.
  Alias occurrence and expansion budgets remain in force.

Regressions cover typed parsing, both value loaders, CST and the original
fuzz inputs. The default suite passed 6,711 tests with two existing ignores.
The alloc-only host runs passed 2,004 baseline and 2,145 portable-feature
tests, including query and anchor regressions. Optional unit tests now import
alloc helpers and gate only I/O tests on std. A deterministic key-inspection
work bound replaces the wall-clock nesting check and rejects a restored
whole-stack scan. Its counters are compiled only for tests. All-feature
clippy passed with warnings denied. Full campaign rechecks and release-ref
CI remain acceptance evidence, not conclusions of this source review.

Feature, target and MSRV declarations remain unchanged. The optional std
filesystem dependency now requires patched rustix 1.1.6; the resolved core
lock already used that version. An isolated Cargo resolver probe accepts
1.1.4 with the previous requirement and rejects it with the patched minimum. The
local graph uses an untracked core path override until the registry crate
exists. The release workflows now guard signing and GitHub release creation
when a tag dispatch requests a dry run. The version gate also checks every
tracked Cargo lock for stale family versions.

## Session admission and executable references

queued-reader interleaving fails before the fix and passes afterward;

failures or ignores. Strict clippy, deny and the existing vet criteria pass.

1.89.0 remain unchanged. This automated source review does not replace
independent security review or exact registry-source verification.

resources and readable tool-failure results. Client root configuration uses
`--root`; the server does not implement the previously documented root
environment variable. Timeouts cannot cancel already-running blocking work;

measures core primitives and cannot establish live SDK dispatch latency.

even after valid responses. Their real-server regression suite passes all
four cases, including the observed exit-status failure. CI repeats the
examples on Linux, macOS and Windows; hosted outcomes are separate evidence.
